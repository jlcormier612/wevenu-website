# Revenue $114,900 vs $64,500 — reconciliation

**Date:** 2026-11-12  
**Venue:** The Willow Grove (Sandbox)  
**Range:** November 2026  

## What we saw

| Surface | Amount |
| --- | ---: |
| Contracted headline (`canonical_gross_booked_revenue`) | **$64,500** |
| Revenue by source / by category row totals (pre-fix) | **$114,900** |

## Root cause (unintentional clock mismatch)

| Path | Population clock |
| --- | --- |
| Contracted headline | First non-cancelled **`events.booked_at`** per client (RPC) |
| By-source / by-category (pre-fix) | **`canonical_bookings.booked_at`** (signed contract + deposit proxy) |

For November 2026 on Willow Grove these clocks select **different client cohorts**:

- Event-booked cohort invoice sum → **$64,500** (matches headline)
- Canonical financially-committed cohort invoice sum → **$114,900**

So the breakdowns were not a second definition of “Contracted” — they were a **different booking population** under the same date picker. Copy did not say so; comments claimed category totals should match the headline.

## Resolution (candidate)

1. `listGrossBookedRevenueClientIds(window)` — same `events.booked_at` population as the RPC.  
2. `getGrossBookedRevenueByCategory` and `getGrossBookedRevenueByAcquisitionSource` use that helper.  
3. Revenue page copy states breakdowns should sum to the Contracted headline.  
4. Regression: `lib/metrics/revenue-breakdown-alignment.test.ts`.

**Period net vs AR** unchanged: Period net remains Contracted − Collected with mixed clocks; not current receivables.
