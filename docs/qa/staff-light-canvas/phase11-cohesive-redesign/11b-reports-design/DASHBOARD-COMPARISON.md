# Phase 11B — Reports vs Dashboard

| Question | Answer |
|---|---|
| Same product? | **Yes** — reuse Snapshot tokens (eucalyptus header, green mist, botanical pale, ivory+blush header). Same charcoal type, warm borders, canvas page. |
| More analytical than Dashboard? | **Yes** — Charts, cohort tables, source breakdowns, and detail panels stay **white**. Color is limited to KPI/funnel wells, not every Card. Dashboard Snapshot is denser color; Reports keeps more white “workspace.” |
| Color families consistent? | **Yes** — Sales/Bookings/Money/Owed/Ops map 1:1 with meaning across Overview and dedicated pages (see `COLOR-MATRIX.md`). |
| Enough personality vs white wall? | **Yes** — Funnel strip + KPI tones break the monochrome; Phase 10 intro already supplies hospitality landmark. |
| Avoided excessive color? | **Yes** — Max ~4 family treatments + white; Saved/lists/charts unlabeled by family fills. |
| Zero / empty? | Outstanding 0 → white; empty charts keep dashed/muted copy on white; no blush empty states. |
| Long labels / large $ / odd trends? | Tones are surface-only; typography and comparison sentences unchanged; grid auto-rows-fr preserved. |
| Differs from Dashboard intentionally? | Reports adds **ops/calm** for Events; Dashboard has no Events KPI. Reports Funnel is multi-clock educational — colored tiles reinforce family, not a conversion staircase. |
