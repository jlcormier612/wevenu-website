## 1. What are the three questionnaires for?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners, managers, and coordinators

**Concise explanation:** Hello to Cheers includes three separate forms for different moments in an event. The **Client Planning Questionnaire** starts the planning conversation after booking. **Final Details** confirms execution details closer to the event. **Post-Event Feedback** gathers the client's experience after the event. Each event has its own instance and status for each form.

**Steps:**
1. Open **Events** and choose the event.
2. Open **Questionnaires** in the Planning area.
3. Choose the form that matches the information you need.
4. Review the draft before sending it to the client.

**Navigation path:** Events → select an event → Planning → Questionnaires

**Limitations:** Creating or reviewing a questionnaire does not send it. Draft, Sent, and Submitted are separate states. This draft does not cover withdrawing or reopening forms.

## 2. How do I customize a questionnaire template?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners, managers, and coordinators who maintain reusable client forms

**Concise explanation:** Questionnaire & Feedback templates are reusable starting points for the Client Planning Questionnaire, Final Details, and Post-Event Feedback. You can begin with a Hello to Cheers form type, then customize the included questions, required questions, wording, custom questions, and order for your venue.

**Steps:**
1. Open **Library → Questionnaires & Feedback**.
2. Choose an existing template, or select **New questionnaire** and choose the form type it is based on.
3. Edit the template's questions and settings.
4. Save the template.
5. When you use the template for an event, Hello to Cheers creates a draft questionnaire on that event.
6. Review the event draft before sending it.

**Navigation path:** Library → Questionnaires & Feedback

**Limitations:** Using a template creates an event-specific draft; it does not send the questionnaire. The event draft is a snapshot, not a live link to later template edits. A template can only be applied while the event questionnaire is still a draft.

## 3. Where do questionnaire answers go?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners, managers, and coordinators reviewing client responses

**Concise explanation:** Each questionnaire question has a defined destination. Some answers update an established event fact, such as a confirmed guest count. Some fill operational fields on the questionnaire, such as meal notes or emergency contact details. Narrative answers remain with the questionnaire response so the team can review them without creating duplicate records.

**Steps:**
1. Open **Events** and choose the event.
2. Open **Questionnaires** in the Planning area.
3. Open a submitted questionnaire.
4. Review the answer rows shown for that form.
5. Use the event's established workspace when you need to manage an authoritative event fact.

**Navigation path:** Events → select an event → Planning → Questionnaires

**Limitations:** Not every answer updates another product area. Display-only prompts are not stored as new facts. Narrative responses remain questionnaire information unless the question has an explicit destination.

## 4. How do I build an event Timeline from a template?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners, managers, and coordinators building a working schedule

**Concise explanation:** A Timeline Template gives an event an editable starting schedule. Applying a template copies its entries into the event. The event Timeline can then be changed without changing the Library template.

**Steps:**
1. Open **Events** and choose the event.
2. Open the event's **Timeline**.
3. If the Timeline is empty, choose a template in the setup card and select **Apply**. If entries already exist, select **Use Template**.
4. Choose one of your Timeline Templates or an available Hello to Cheers starter.
5. Review the warning if the Timeline already has entries. Applying another template adds entries; it does not remove or replace existing entries.
6. Apply the template, then review the copied entries and times in the working Timeline.

**Navigation path:** Events → select an event → Timeline  
**Template library:** Library → Timeline Templates

**Limitations:** Applying a template creates an editable copy, not a live link. Later template edits do not update the event. Existing Timeline entries remain in place when another template is applied. Review times after applying, especially when the event does not yet have a start time.

## 5. What is the difference between Client Planning and Venue Planning?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners, managers, and coordinators choosing a planning checklist

**Concise explanation:** Client Planning and Venue Planning are separate checklist types. **Client Planning** is work intended for the client. Applying it creates a private Draft that the venue can review before choosing **Release to Client**. **Venue Planning** is internal operational work and becomes Active when it is applied.

**Steps:**
1. Open **Events** and choose the event.
2. Open the **Planning** area.
3. Choose a Client Planning or Venue Planning template.
4. Apply the template.
5. For Client Planning, review the Draft and release it only when it is ready for the client.
6. For Venue Planning, begin working from the Active checklist.

**Navigation path:** Events → select an event → Planning

**Limitations:** Applying Client Planning does not make it visible to the client; Release is a separate action. Venue Planning does not use the Draft-to-Release lifecycle. These are independent checklists, not two views of one checklist.

## 6. How do I create and apply a Planning Template?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Venue owners and team members who maintain repeatable planning processes

**Concise explanation:** Planning Templates let your venue build reusable Client Planning or Venue Planning checklists. A template can contain milestones and tasks with event-relative or fixed due dates, ownership and visibility, dependencies, reminders, attachments, links, and event-day designation.

**Steps:**
1. Open **Library → Planning Templates**.
2. Select **New template**.
3. Choose Client Planning or Venue Planning.
4. Start with a standard checklist, an existing template, a blank template, or an imported checklist.
5. Add and organize milestones and tasks, then save your changes.
6. Open an event and go to **Planning**.
7. Choose the matching template and apply it.

**Navigation path:** Library → Planning Templates  
**Apply to an event:** Events → select an event → Planning

**Limitations:** Applying a template creates event-specific tasks. Later edits to the Library template do not update an event that already uses it. Client Planning remains private until it is released. This workflow does not provide an event-level ad-hoc task creation path.

## 7. How do I use Task Center?

**Status:** DRAFT — NOT PUBLISHED

**Audience:** Coordinators and venue teams managing planning work across events

**Concise explanation:** Task Center brings attention-needed work from all active events into one workspace. It organizes tasks into Overdue, Blocked, Due Today, Due This Week, and Upcoming sections. **My Tasks**, **Team Tasks**, and **All Tasks** are different perspectives over the same task set.

**Steps:**
1. Open **Tasks → Task Center**.
2. Choose **My Tasks**, **Team Tasks**, or **All Tasks**.
3. Start with Overdue, Blocked, and Due Today items.
4. Open an event from a task when you need the full planning context.
5. Complete or waive an eligible task from Task Center.

**Navigation path:** Tasks → Task Center

**Limitations:** My Tasks is a view based on staff assignment, not a separate permission boundary. Blocked tasks wait on their dependency. Event tasks originate from applied Planning Templates; Task Center does not create or delete ad-hoc event tasks.
